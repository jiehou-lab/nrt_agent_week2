If python3 server.py looks like it has frozen, it is working. An stdio MCP server sits waiting for messages on standard input — a blinking cursor and no output is exactly right. Press Ctrl C to stop it. You never need to start it by hand; Claude Code launches it for you.

Package:

Demo2_MCP_Tissue_Analyzer.zip

This guide uses the same synthetic histology-like images, but now the tool is exposed through MCP.

The main teaching goal is to show that the scientific workflow remains similar while the tool interface becomes explicit and machine-readable.

1. Unzip the package

unzip Demo2_MCP_Tissue_Analyzer.zip
cd Demo2_MCP_Tissue_Analyzer

Inspect. The second command is the one that matters — .mcp.json starts with a dot, so it is hidden from a plain ls:

ls -R | head -40
ls -a

If you would rather see a tree. macOS and Linux do not ship tree by default. Install it with brew install tree (macOS) or sudo apt install tree (Ubuntu / WSL), then run tree -a -L 3 — the -a is what shows .mcp.json. On Windows, tree /F works with nothing to install, or use Get-ChildItem -Force -Recurse -Depth 2.

Important files include:

server.py
.mcp.json
tools/
data/
previews/
results/
EXPECTED_SYNTHETIC_RESULTS.md

Part A — Test the MCP-adapted tools directly

4. Run the MCP-adapted analysis script

Example:

python3 tools/analyze_tissue.py \
  --slide data/case_mild_injury_histology.pgm \
  --magnification 20 \
  --damage-threshold-fraction 0.45 \
  --out results/mild_mcp_analysis.json

Inspect:

cat results/mild_mcp_analysis.json

5. Run the classifier

The MCP classifier expects the saved analysis JSON as its input.

python3 tools/classify_tissue.py \
  --features results/mild_mcp_analysis.json \
  --out results/mild_mcp_classification.json

Inspect:

cat results/mild_mcp_classification.json

6. Demonstrate stronger validation

Try an invalid threshold:

python3 tools/analyze_tissue.py \
  --slide data/case_mild_injury_histology.pgm \
  --magnification 20 \
  --damage-threshold-fraction 50

This version should reject the invalid scale instead of silently treating 50 as a valid fraction.

7. Inspect the MCP configuration

cat .mcp.json

The project should register a local MCP server called:

tissue-analyzer

8. Inspect the MCP server

less server.py

Look for the tool definitions:

analyze_tissue
classify_tissue

The MCP layer makes explicit things such as:

magnification ∈ {10, 20, 40}
damage_threshold_fraction ∈ [0, 1]

8A. Practice Claude Code MCP management commands

Before starting the interactive Claude Code session, try the MCP-management commands from a normal terminal.

List configured MCP servers

claude mcp list

For this demo, look for:

tissue-analyzer

This command is useful for checking both whether the server is configured and whether Claude Code can connect to it.

Typical states conceptually mean:

Connected             -> configuration exists and Claude Code can connect
Needs authentication  -> configuration exists but login is required
Failed to connect     -> configuration exists but the server could not start/connect

Inspect one MCP server

claude mcp get tissue-analyzer

Use this to inspect details for one server, including how Claude Code starts it.

For this project, the server process should be equivalent to:

python3 server.py

This command is especially useful when diagnosing the wrong Python interpreter, wrong command, wrong scope, or server startup failure.

Understand scopes

Claude Code MCP configuration can use different scopes:

local
  available only to you for the current project

project
  stored in the project's .mcp.json
  can be shared with the repository

user
  available to you across projects

For this classroom demo, project scope is useful because students can see the .mcp.json file directly.

Add this local stdio MCP server manually

The package already contains .mcp.json, so normally you do not need to add it again. As practice, the equivalent command is:

claude mcp add \
  --scope project \
  --transport stdio \
  tissue-analyzer \
  -- python3 server.py

The -- separates Claude Code options from the command used to start the MCP server.

Conceptually:

name       = tissue-analyzer
scope      = project
transport  = stdio
command    = python3 server.py

After adding it, verify:

claude mcp list
claude mcp get tissue-analyzer

Make the Python environment explicit

If you created a virtual environment:

python3 -m venv .demo_venv
source .demo_venv/bin/activate

you can register the MCP server with the exact interpreter:

claude mcp add \
  --scope project \
  --transport stdio \
  tissue-analyzer \
  -- .demo_venv/bin/python3 server.py

This avoids ambiguity about which Python starts the MCP server.

You can also check:

which python3
python3 --version

Remove an MCP server registration

claude mcp remove tissue-analyzer --scope project

Then verify:

claude mcp list

Removing the registration does not delete server.py, the analysis tools, models, or data. It only removes the Claude Code configuration that tells Claude how to connect to the MCP server.

Restore it with:

claude mcp add \
  --scope project \
  --transport stdio \
  tissue-analyzer \
  -- python3 server.py

Reset a previously rejected project MCP decision

If a valid .mcp.json exists but Claude Code still does not load the project MCP server, you can reset stored project MCP approval choices:

claude mcp reset-project-choices

Then restart Claude Code from the project root.

Terminal MCP commands vs. /mcp

From a normal terminal:

claude mcp list
claude mcp get tissue-analyzer
claude mcp add ...
claude mcp remove ...

These commands inspect or modify MCP configuration.

Inside an active Claude Code session:

/mcp

opens the interactive MCP status/management panel.

A useful mental model is:

Terminal CLI
    configure and inspect MCP servers

Claude Code /mcp
    inspect/manage MCP servers in the current session

Suggested five-minute practice sequence

claude mcp list
claude mcp get tissue-analyzer

If it is already configured, do not add a duplicate.

For practice, you can remove and restore it:

claude mcp remove tissue-analyzer --scope project
claude mcp list

Restore:

claude mcp add \
  --scope project \
  --transport stdio \
  tissue-analyzer \
  -- python3 server.py

Verify again:

claude mcp list
claude mcp get tissue-analyzer

Then start Claude Code:

claude

and inside Claude Code run:

/mcp

This demonstrates the lifecycle:

configure -> inspect -> remove -> restore -> connect -> use tools

Part C — Demonstrate MCP validation

16. Try an invalid threshold through MCP

Prompt:

Call analyze_tissue with:

slide = data/case_mild_injury_histology.pgm
magnification = 20
damage_threshold_fraction = 50

The MCP layer should reject the invalid range before normal execution.

17. Try invalid magnification

Prompt:

Call analyze_tissue with:

slide = data/case_mild_injury_histology.pgm
magnification = 25
damage_threshold_fraction = 0.45

The interface should reject the unsupported magnification.

18. Compare natural language with the formal schema

Prompt:

Analyze data/case_mild_injury_histology.pgm
at 20x magnification with a 50% damage threshold.
Use the MCP tool.

Claude should convert the natural language into:

magnification = 20
damage_threshold_fraction = 0.5

before calling the tool.

This is the key contrast with the repository-only version.

19. Main lecture comparison

Original repository

Claude searches files
→ infers script
→ infers parameter names
→ infers valid values
→ generates command

MCP version

Claude discovers tool
→ reads formal schema
→ provides structured arguments
→ invalid values can be rejected
→ structured result returned

20. Main takeaway

The MCP layer does not replace the tissue-analysis workflow.

It makes the capability easier for an agent to discover and call reliably.

The same scientific computation is now accessed through a clearer contract.

Appendix — Claude Code MCP Command Reference

The following table summarizes the MCP-related commands used in this demo.

Command Where to run it What it does Example for this demo
claude mcp list Normal terminal Lists MCP servers Claude Code knows about and shows their connection/status information. claude mcp list
claude mcp get <name> Normal terminal Shows the configuration/details for one MCP server. Useful for checking command, scope, transport, and troubleshooting. claude mcp get tissue-analyzer
claude mcp add ... Normal terminal Registers a new MCP server with Claude Code. claude mcp add --scope project --transport stdio tissue-analyzer -- python3 server.py
claude mcp remove <name> --scope <scope> Normal terminal Removes an MCP server registration from the specified scope. It does not delete the actual server code. claude mcp remove tissue-analyzer --scope project
claude mcp reset-project-choices Normal terminal Resets stored trust/approval choices for project MCP servers so Claude Code can ask again. Useful if you previously selected “Do not trust.” claude mcp reset-project-choices
claude mcp list after add/remove Normal terminal Confirms whether the MCP server is currently registered and whether Claude can connect to it. claude mcp list
claude Normal terminal Starts Claude Code in the current project directory. Start it from the directory containing .mcp.json. claude
/mcp Inside Claude Code Opens the interactive MCP status/management panel for the current session. /mcp
which python3 Normal terminal Shows which Python interpreter will be used when python3 is invoked from the current shell. Useful before starting an stdio MCP server. which python3
python3 --version Normal terminal Confirms the Python version associated with the active interpreter. python3 --version
source .demo_venv/bin/activate Normal terminal Activates the project virtual environment before running Claude Code or registering the MCP server. source .demo_venv/bin/activate

Common MCP add patterns

Project-scoped stdio server

claude mcp add \
  --scope project \
  --transport stdio \
  tissue-analyzer \
  -- python3 server.py

Project-scoped stdio server using an explicit virtual environment

claude mcp add \
  --scope project \
  --transport stdio \
  tissue-analyzer \
  -- .demo_venv/bin/python3 server.py

The explicit interpreter version is often better for a classroom demo because it removes ambiguity about which Python environment starts the MCP server.

MCP scope reminder

Scope Meaning Typical use
local Available only to you for the current project Personal project-specific setup
project Stored with the project, typically through .mcp.json Shared classroom/repository configuration
user Available to you across projects Personal globally useful MCP servers

For this demo, project scope is the clearest choice because students can inspect the .mcp.json file directly.

Useful troubleshooting sequence

If tissue-analyzer does not appear inside /mcp, try:

which python3
python3 --version

claude mcp list
claude mcp get tissue-analyzer

If you previously rejected the project MCP server:

claude mcp reset-project-choices

Then restart:

claude

and inside Claude Code run:

/mcp

If the server is still missing, re-register it:

claude mcp add \
  --scope project \
  --transport stdio \
  tissue-analyzer \
  -- python3 server.py

Then confirm:

claude mcp list

A compact mental model is:

claude mcp add/remove/get/list
    -> configure or inspect MCP from the terminal

/mcp
    -> inspect/manage MCP inside the active Claude Code session
